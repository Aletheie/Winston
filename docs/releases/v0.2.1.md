# Winston 0.2.1

This release adds a workspace for saved highlights, simplifies importing books, and improves catalog recovery, Kindle transfers, and large-library browsing.

## What changed

- **Highlights:** browse passages by book, mark favorites, add tags and reflections, revisit them in review sessions, and export them as Markdown. Favorites, reflections, and review state are included in catalog snapshots.
- **Direct imports:** files from Finder, Calibre, catalogs, and Kindle enter the library after inspection. Exact duplicates are skipped; results and failures remain in **Review & Operations**. The separate pre-import review dialog has been removed.
- **Kindle:** MTP sends prepare compatible personal documents and embedded covers without changing the library original. Sync plans retain their selected scope, device profiles reconnect more reliably, and cover repair can retry older embedded-cover transfers.
- **Library browsing:** index changes are batched, search filters are compiled once per query, and cover decoding and caches have explicit memory limits. Recently Added counts expire correctly, and cancelled searches cannot replace newer results.
- **Recovery and backups:** interrupted recovery can resume from validated checkpoints. Backup destinations inside the library are rejected, including paths reached through symbolic links. Background asset inspection uses bounded reads and shared batches.
- **Catalogs:** downloads enforce size limits and clean up temporary files on failure. Private cover requests keep authentication tied to the approved origin.
- **Interface:** the empty library focuses on adding books, disconnected Kindle help stays reachable, library tools are grouped in the toolbar, and changing language offers a relaunch action. Czech translations and both help languages have been updated.

## Installing

Download the DMG or ZIP, quit Winston, and replace the app in Applications. This build is for **Apple Silicon Macs running macOS 26.4 or newer**.

The app is signed with an Apple Development certificate and **is not notarized**. macOS may require approval in Privacy & Security for its first launch. Updating remains manual.

Keep a backup of your library before updating. Users upgrading from 0.1 should follow the [0.2 catalog migration instructions](v0.2.md#before-updating).

## Validation and remaining limits

- 983 unit tests passed in both Debug and Release, including recovery, migration, import, sync, and highlights regressions.
- Four UI scenarios passed: empty-library setup, import to Kindle sync planning, highlight editing and review, and selection while browsing 1,000 books.
- MTP transfers have been verified on a current Kindle. Large-library changes reduce repeated work; smooth scrolling on every library and display configuration is not guaranteed.
- Native Kindle conversion produces MOBI; AZW3 and less common formats still require Calibre. Intel builds, iCloud sync, notarization, and automatic updates remain unavailable.

# Winston 0.2.2

This release hands books to ElevenReader for listening and makes large libraries lighter on disk and memory.

## What changed

- **ElevenReader:** **Listen in ElevenReader** in the book context menu, the inspector, and the Book menu picks the best DRM-free file (EPUB, then PDF, DOCX, HTML, TXT). It either opens your ElevenReader web library with the file selected in Finder for drag-and-drop, or sends it to your iPhone with AirDrop. ElevenReader has no public import API, so Winston uploads nothing itself. Kindle-only formats and DRM-protected files are explained instead of sent. The **ElevenReader** sidebar filter lists only books that can be handed off.
- **Full-text search:** the content index (schema v3) updates only the sections of changed books and skips unchanged documents. The v2 index migrates in one transaction.
- **Covers:** derived cover thumbnails are limited to 256 MiB and 20,000 files, removing the least recently used first. A cover that has decoded still displays when the disk cache cannot be written. Grid cards use one opaque surface instead of stacked materials.
- **Catalogs and Discover:** a cancelled and restarted OPDS download can no longer be cleared or overwritten by the earlier attempt. Failed Discover images are retried instead of cached, and valid small images are accepted.
- **Settings:** every preference uses the same defaults store.
- **Internals:** cover application, paging, edition-candidate construction, catalog commits, and checksum reading share single implementations.

## Installing

Download the DMG, quit Winston, and replace the app in Applications. This build is for **Apple Silicon Macs running macOS 26.4 or newer**.

The app is signed with an Apple Development certificate and **is not notarized**. macOS may require approval in Privacy & Security for its first launch. Updating remains manual. Keep a backup of your library before updating.

## Validation and remaining limits

- 1,014 unit tests passed in Debug. The release-readiness and catalog-write audits passed.
- The ElevenReader menus and sidebar filter, AirDrop handoff, and web upload have not been verified manually. The browsing UI test does not yet confirm that fixture covers render, and no physical Kindle verification was performed for this release.
